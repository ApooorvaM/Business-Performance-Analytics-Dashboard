# 📊 Sales & Customer Performance Dashboard | Tableau

An interactive Business Intelligence dashboard built in **Tableau** to analyze **Sales Performance** and **Customer Performance** using the Tableau Superstore dataset.

The project consists of **two interconnected dashboards** with navigation buttons, interactive filters, Year-over-Year (YoY) comparison, KPI tracking, trend analysis, and customer insights to support business decision-making.

# 📌 Project Overview

This project is an interactive Tableau dashboard developed to monitor business performance from both **Sales** and **Customer** perspectives.

The dashboards provide a comprehensive view of business performance through KPI cards, trend analysis, product-level insights, weekly performance tracking, customer analytics, and interactive filtering.

Users can seamlessly switch between the dashboards using built-in navigation buttons while applying filters to analyze data by year, geography, and product hierarchy.

---

# 🎯 Business Objective

The objective of this dashboard is to help business users:

- Monitor overall sales performance.
- Compare current year performance with the previous year.
- Analyze profit trends.
- Track product category performance.
- Identify profitable and loss-making sub-categories.
- Understand weekly sales and profit fluctuations.
- Analyze customer purchasing behaviour.
- Identify top-performing customers.
- Enable interactive business analysis using multiple filters.

---

# 📊 Dashboard Overview

The project contains **two interactive dashboards**.

## 1️⃣ Sales Dashboard

The Sales Dashboard provides an overview of business performance by comparing the selected year against the previous year.

### KPIs

- **Total Sales**
- **Total Profit**
- **Total Quantity**

Each KPI includes:

- Current Year value
- Percentage change vs Previous Year
- Monthly trend line
- Highest performing month
- Lowest performing month

### Visualizations

#### 📈 Sales & Profit by Subcategory

Displays:

- Current Year Sales
- Previous Year Sales
- Current Year Profit
- Loss-making subcategories

Helps identify:

- Best performing products
- Underperforming products
- Loss generating subcategories

---

#### 📉 Sales & Profit by Week

Weekly comparison of:

- Sales
- Profit

Highlights:

- Above Average Weeks
- Below Average Weeks

Reference lines are used to indicate average weekly performance.

---

## 2️⃣ Customer Dashboard

The Customer Dashboard focuses on customer behaviour and purchasing patterns.

### KPIs

- **Total Customers**
- **Total Sales per Customer**
- **Total Orders**

Each KPI includes:

- Current Year value
- Percentage change vs Previous Year
- Monthly trend
- Highest performing month
- Lowest performing month

---

### Visualizations

#### 👥 Customer Count by Number of Orders

Shows the distribution of customers based on the number of orders placed.

Helps identify purchasing frequency and customer engagement.

---

#### 🏆 Top 10 Customers

Displays the top customers ranked by performance.

Includes:

- Rank
- Customer Name
- Max Order Date
- Current Year Profit
- Current Year Sales
- Distinct Number of Orders
